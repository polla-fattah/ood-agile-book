*Companion to Object Oriented Development and Agile Practices*

{{< book-toc depth=2 >}}

This section contains the official code companions, lab walkthroughs, and verified solutions for each chapter of *Object Oriented Development and Agile Practices*. 

### Companion Content Structure

Every chapter's companion provides:
1. **Executable Java Code Listings**: Production-quality Java classes and suites conforming to the running Campus Equipment Lending System.
2. **Step-by-Step Code Walkthroughs**: Line-by-line analyses of design decisions, type safety, invariants, and exception handling.
3. **Lab Solutions & Exercises**: Model answers for both required core labs and optional team extensions.
4. **Verification Records & Fault Experiments**: Documented test suite outputs (`mvn verify`), mutation/fault analysis records, and reproducible compiler checks.
5. **Delta Checkpoints**: Clear listings of new or modified files built on top of preceding chapter checkpoints.

Select a chapter companion from the sidebar or table of contents to view its complete code listings and solutions.
