# Internal folder (NOT FOR PUBLISHING)

Everything in this folder is working material from the first-draft cleanup of 13 October 2026.

- `backup_before_cleanup/`: every chapter file exactly as it was before the cleanup (30 files).
- `evidence/`: the text that was removed from the published chapter files (one file per chapter, verbatim, with the file and section it came from). This is the verification evidence: runs, JDK and Maven versions, test counts, SHA-256 manifests, notes about earlier versions.
- `Cleanup_Change_Log.md`: for each chapter, what was removed or rewritten and where it went.
- `Cleanup_Todo.md`: the chapter-by-chapter to-do list.
- `cleanup_lib.py` and `chNN*.py`: the scripts that made the edits, kept so that each edit can be repeated or reviewed.
