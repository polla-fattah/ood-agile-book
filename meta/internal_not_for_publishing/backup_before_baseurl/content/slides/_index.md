Lecture decks supporting the weekly schedule of *Object Oriented Development and Agile Practices*. 

Each slide deck correlates with the weekly reading and practical activities:
- **Presentation Mode**: Open any deck, use arrow keys or the space bar to navigate, and press **F** for fullscreen.
- **Handouts & Export**: Decks format to one slide per page in landscape orientation for printable handouts or PDF generation (`Ctrl + P`).

### Lecture Decks

* [Week 01: Foundations: Software That Can Change & OO Beyond Syntax](/oop-and-agile/slides/week-01/) (54 slides; 2.5-3 hours)
  * Orientation, Invariants, Encapsulation, `List.copyOf`, Cohesion/Coupling, UML Class Modelling, Deliberate Faults, AI Claim Classification.
* [Week 02: Agile Development, Backlogs & Acceptance Criteria](/oop-and-agile/slides/week-02/) (52 slides; 2.5-3 hours)
  * Uncertainty, Feedback Loops, Scrum vs Kanban, WIP Limits, User Stories, INVEST, Given-When-Then Scenarios, Definition of Done, Planning Poker, AI Story Auditing.
* [Week 03: From Requirements to an Iteration: Planning & CI](/oop-and-agile/slides/week-03/) (54 slides; 2.5-3 hours)
  * Milestone 1 Vision, Scope vs Assumptions, Wireframes, Capacity Planning, WBS, Git Hygiene, AAA Testing, CI Pipelines, Deliberate Faults.
* [Week 04: SOLID I: Single Responsibility, Extension & Substitutability](/oop-and-agile/slides/week-04/) (54 slides; 2.5-3 hours)
  * Change Pressures, Fowler Smells, PMD 7.28.0 Analysis, SRP Formatter Extraction, OCP BorrowingPolicy, LSP IntHistory Counterexample, Bounded AI Refactoring.
* [Week 05: SOLID II: Interfaces, Dependency Inversion & Composition](/oop-and-agile/slides/week-05/) (48 slides; 2.5-3 hours)
  * Notification Pressures, Fat Interfaces vs Role Interfaces (ISP), Dependency Inversion (DIP), Constructor Injection, Composition Roots, DemoContainer IoC Walkthrough, Quiz 1 Revision.
* [Week 06: Testing as a Design Practice: TDD & Test Doubles](/oop-and-agile/slides/week-06/) (48 slides; 2.5-3 hours)
  * Green Build Illusion, AQ-01..05 Criteria, Red-Green-Refactor Rhythm, Clock Abstraction, Meszaros Test Double Taxonomy, Mockito 5.20.0, Mutation Testing, Milestone 2 Checklist.
* [Week 07: Creational Patterns & Object Construction](/oop-and-agile/slides/week-07/) (45 slides; 2.5-3 hours)
  * Creational Smells, Factory Method vs Simple Factory, Abstract Factory Families, Fluent Builder Invariants, Legacy Directory Adapter, Decorator Order, Midterm Practice.
* [Week 08: Designing Changing Behaviour: Core Patterns](/oop-and-agile/slides/week-08/) (51 slides; 2.5-3 hours)
  * 4 Behavioural Questions, Strategy Contracts, State Pattern & 20-Cell Transition Table, Atomic State Assignment, Observer NotificationPublisher, Snapshot Semantics, Command Execution-Time Evaluation, Appendix E Book Review Checkpoint.
* [Week 09: Layered Architecture & Package Principles](/oop-and-agile/slides/week-09/) (46 slides; 2.5-3 hours)
  * 5 Architectural Layers, Permitted Dependency Matrix, Dependency Inversion with ReservationRepository, Sequence Diagram, Package Principles (REP, CCP, CRP, ADP, SDP, SAP), Instability Metric (I), Evans DDD Entities vs Value Objects, Milestone 3 Checklist & ADR-010.
* [Week 10: Refactoring & Working Safely with Legacy Code](/oop-and-agile/slides/week-10/) (45 slides; 2.5-3 hours)
  * Feathers Legacy Definition, 5-Stage Escape Route, Smells as Change Prompts, Parameter Seam with LocalDate, Characterisation Testing Loop, Pinning Suspected Defects, Extract Method/Class (FinePolicy record), Rollback Discipline, Technical Debt Registers, Quiz 2 Clinic.
